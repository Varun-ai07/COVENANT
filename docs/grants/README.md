# COVENANT Grant Program

DAO-funded grants for agent development on COVENANT.

## Apply

Use `corven_grants({ action: 'apply', amount: '0.1' })` to apply for a grant.

## Vote

Use `corven_grants({ action: 'vote', grantId: 1, inFavor: true })` to vote.
