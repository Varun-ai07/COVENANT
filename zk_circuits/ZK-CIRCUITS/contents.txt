CIRCUIT 1 — REPUTATION RANGE PROOF
==================================

PURPOSE:
Prove:

```
Reputation >= threshold
```

WITHOUT revealing actual reputation.

---

## PRIVATE INPUTS

Reputation      → actual score (0–1000)
salt            → random non-zero value

---

## PUBLIC INPUTS

threshold       → minimum required reputation
Agentaddress    → binds proof to agent

---

## OUTPUTS

isEligible      → 1 if Reputation >= threshold
Commitment      → Poseidon(agentAddress, reputation, salt)

---

## WHAT IT GUARANTEES

✔ Reputation is within [0,1000]
✔ Threshold is within [0,1000]
✔ Reputation >= threshold
✔ Salt is non-zero
✔ Commitment binds agent → reputation

---

## INPUT GENERATION

1. Choose:
   Reputation = actual score (e.g. 720)

2. Choose:
   salt = random large number (NEVER 0)

3. Compute:
   Commitment = Poseidon(Agentaddress, Reputation, salt)

---

## SAMPLE input.json

{
"Reputation": "720",
"salt": "987654321",

"threshold": "500",
"Agentaddress": "12345678901234567890"
}

---

## IMPORTANT NOTE

This circuit currently does NOT prevent replay.

To upgrade later:
→ add nullifier = Poseidon(salt, Agentaddress)

🧠 CIRCUIT 4 — IDENTITY BINDER
🎯 PURPOSE

This circuit proves:

“I control a private key that deterministically maps to a public identity,
and I’m generating a unique, non-replayable proof for a specific context.”

Without revealing:

❌ privateKey
🔐 WHAT THIS CIRCUIT ACTUALLY DOES

It combines 3 things:

1. Identity derivation (private key → public key)
2. Identity commitment (public key → hash)
3. Replay protection (nullifier)
⚙️ STEP-BY-STEP EXPLANATION
1. Private Key → Public Key
component pubKey = BabyPbk();
pubKey.in <== privateKey;

👉 This uses Baby Jubjub elliptic curve

Result:

pubKey.Ax
pubKey.Ay

So now:

privateKey → (Ax, Ay)
2. Public Key → Public Identity Hash
component pubKeyHasher = Poseidon(2);
pubKeyHasher.inputs[0] <== pubKey.Ax;
pubKeyHasher.inputs[1] <== pubKey.Ay;

publickeyHash <== pubKeyHasher.out;

👉 This creates:

publickeyHash = Poseidon(pubKey)

This becomes your:

agent identity commitment
3. Nonce Check
component nonceCheck = IsZero();
nonceCheck.in <== nonce;

⚠️ IMPORTANT:

This currently does NOT enforce anything.

Right now:

nonce can be 0 → BAD

👉 You need:

nonceCheck.out === 0;

Otherwise:

replay protection is weak
4. Nullifier (CRITICAL)
nullifier = Poseidon(privateKey, nonce, contextHash)

👉 This creates:

unique proof ID per context

So:

same key + same context + same nonce → same nullifier
different nonce → different nullifier
5. Address Binding
signal addressSquared <== address * address;

👉 This is a trick:

forces address into constraint system

Without this:

address is UNUSED → attacker can spoof it
🧠 WHAT THIS CIRCUIT GUARANTEES
✔ Prover owns a valid private key
✔ Public key is derived correctly
✔ Identity commitment is valid
✔ Proof is tied to context (contextHash)
✔ Proof is non-replayable (via nonce)
✔ Address is bound to proof

Right now:

nonceCheck.in <== nonce;

Fix it:

nonceCheck.out === 0;

Otherwise:

nonce = 0 allowed → replay risk
